# 🌸 Lotus Blooming Animation

An elegant and interactive lotus flower blooming animation developed using **HTML, CSS, and JavaScript**. This project illustrates the beautiful transformation of a lotus from a closed bud into a fully bloomed flower through smooth animations and visually appealing effects.

## ✨ Features

- 🌱 **Bud-to-Flower Animation:** Watch a lotus gradually bloom from a closed bud.
- 🌸 **Layered Petal Animation:** Petals unfold layer by layer to create a natural blooming effect.
- 🎨 **Beautiful Visual Design:** Pink petals, delicate details, and a visually appealing background.
- ✨ **Smooth Transitions:** CSS animations and JavaScript timing create fluid movements.
- 🌿 **Decorative Elements:** Includes a stem, background effects, and floating particles.

## 🛠️ Technologies Used

- **HTML5** – Structures the animation and SVG elements.
- **CSS3** – Handles styling, gradients, transitions, and animations.
- **JavaScript** – Controls the blooming sequence, petal creation, and animation timing.
- **SVG** – Creates scalable flower shapes and detailed visual elements.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash

   ```

2. Navigate to the project folder:

   ```bash
   cd lotus-animation
   ```

3. Open `index.html` in your web browser.

4. Enjoy watching the lotus bloom! 🌸
